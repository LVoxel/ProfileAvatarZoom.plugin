## 📷 Просмотр аватара и баннера в Discord

Плагин для BetterDiscord, добавляющий функцию просмотра аватара и баннера пользователя в полном размере через контекстное меню.

<div align="center">
  <img src="https://raw.githubusercontent.com/LVoxel/ProfileAvatarZoom.plugin/refs/heads/main/raw/main/assets/preview.png" alt="Превью плагина">
</div>

## ✨ Возможности

- 👁️ Просмотр аватара пользователя в полном размере
- 🖼️ Просмотр баннера профиля пользователя
- 📋 Быстрое копирование ссылок на изображения
- 🔗 Возможность открыть изображение в браузере
- 🔄 Автоматическое определение анимированных аватаров (GIF)
- ⚠️ Проверка валидности хеша баннера

## 🔧 Использование

1. Нажмите правой кнопкой мыши на аватар или имя пользователя
2. В контекстном меню выберите "Показать аватар и баннер"
3. Просматривайте, копируйте и открывайте изображения в полном размере
